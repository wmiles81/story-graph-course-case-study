# What earns a row

The rulebook is `story-graph/reference/decisions.md`; this is the short form.

## Load-bearing, defined operationally

> A row is **load-bearing** if contradicting it would force another row to change.

That is a graph property, not a matter of taste — which means the tool can compute it, and
the instruction becomes "add a receipt where the graph says it is load-bearing" rather than
"use your judgement."

## The test for a proposition

A sentence earns a Proposition row only if **a later chapter could contradict it.** Facts
that no future chapter can disturb are scenery.

## The emphasis ladder

Narrative attention creates obligation. From weakest to strongest:

**atmosphere · character revelation · clue · setup · motif · red herring**

Only the last four create reader obligations, so only they earn Open Loop rows. The rule
cuts both ways: it also flags high-attention detail that *never* got a row, which is the
more common failure.

## The negative rule

What must **not** become a row: inferred backstory, unnamed walk-ons, scenery that never
returns, anything the prose does not support. Anti-invention is a checklist, not a
sentiment — when a new fact is genuinely needed, it goes in the appropriate registry and is
marked `provisional`.
