# Glossary

**Alias** — a rigid designator: a surface form that denotes one entity in every scene.
Contrast *description*.

**Ambiguous** — a name or trait that two or more entities both claim. Reported, never
resolved by guessing.

**Blast radius** — how much would have to be revisited if a claim turned out to be false:
holders + receipts + dependents (weighted) + irony.

**Canon commit** — the per-chapter, append-only record of what changed.

**Contested** — sources disagree at equal authority, so the tool refuses to pick.

**Description** — a definite description ("the Vampire"), true of whoever qualifies in the
scene. Resolves through a *trait*, never through the alias table.

**Dramatic irony** — the reader knows a claim while a character believes it false, over an
overlapping chapter window.

**Evidence span** — a verbatim quote from a source, hard-verified against the chapter file.

**Holder** — anyone who can hold a stance: an entity, or the reserved holder `reader`.

**Load-bearing** — contradicting it would force another row to change.

**NEEDS-HUMAN** — a proposed row whose quote is real but whose *meaning* is a reading. Never
auto-applied.

**Open loop** — a planted, unresolved element with a `must-fire-by` chapter.

**Proposition** — a claim about the story world, holder-free, with a canon status.

**Provisional** — inferred but not yet backed by a verified quote. An honest state, not a
failure.

**Trait** — an attribute (`vampire`, `alpha`) that a description resolves through.

**Until-ch** — the chapter a stance ends. Without it a stance runs forever and a corrected
belief reads as a contradiction.
