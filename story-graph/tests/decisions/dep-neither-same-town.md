# dep-neither-same-town
- category: dependency
- ask: dependency

## Scene
The Snowfall Creek Public Library sat at the end of the block like a patient gargoyle.
Jonah shouldered through the swinging doors of the Howling Moon.

## Claim
A: Margot is the librarian of Snowfall Creek.
B: Jonah is the sheriff of Snowfall Creek.

## Expect
- depends: neither

## Trap
Sharing a setting is not dependency. Two claims can be true together, be about the same
town, appear in the same chapter, and still need nothing from each other — and a judge
looking for a link will usually find one.
