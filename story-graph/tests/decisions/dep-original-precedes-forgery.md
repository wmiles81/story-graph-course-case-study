# dep-original-precedes-forgery
- category: dependency
- ask: dependency

## Scene
"It was propaganda before the ink was even dry." She held up the Scroll case: the
original text, the one that says what the Treaty really did.

## Claim
A: The original Integration Treaty documents coercive supernatural servitude.
B: The official Integration Treaty is fraudulent propaganda.

## Expect
- depends: b-needs-a

## Trap
Calling the official version propaganda is only true because the original says something
else. The original stands alone; the accusation does not.
